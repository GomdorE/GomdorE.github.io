종이 노트와 메모 앱은 어느 한쪽이 항상 우수한 도구가 아닙니다. 저장할 정보의 수명, 검색 필요성, 사용하는 장소에 따라 적합한 방식이 달라집니다.

## 종이가 나은 경우

**생각을 정리할 때.** 손으로 쓰는 속도는 키보드보다 느립니다. 이 차이 때문에 문장을 적기 전에 내용을 한 번 더 압축하게 됩니다. 빠른 기록보다 생각의 구조화가 목적이라면 종이가 유리할 수 있습니다.

**할 일이 다섯 개 이하일 때.** 짧은 목록은 앱을 열고 분류하는 과정이 오히려 부담이 됩니다. 책상 위에 계속 보이는 종이는 확인 단계가 가장 적습니다.

**화면과 알림을 피해야 할 때.** 스마트폰에서 메모 앱을 열면 다른 알림과 앱도 함께 노출됩니다. 취침 전 기록처럼 방해 요소를 줄여야 하는 상황에서는 종이가 단순합니다.

## 앱이 나은 경우

다음 조건에서는 앱의 검색과 동기화 기능이 분명한 이점이 됩니다.

- 나중에 **검색**해서 찾아야 하는 것
- 여러 기기에서 봐야 하는 것
- 사진이나 링크가 들어가는 것
- 잃어버리면 곤란한 것

## 용도별 추천

| 정보 유형 | 추천 도구 | 이유 |
|---|---|---|
| 오늘 할 일 세 가지 | 종이 | 계속 보이고 즉시 지울 수 있음 |
| 생각의 초안 | 종이 | 입력 속도가 느려 내용을 압축하게 됨 |
| 자료, 링크, 사진 | 앱 | 첨부와 검색이 쉬움 |
| 장기 기록 | 앱 | 백업과 여러 기기 동기화 가능 |
| 나중에 찾아야 할 정보 | 앱 | 키워드 검색 가능 |

## 가장 단순한 운영 방법

처음부터 복잡한 분류 체계를 만들 필요는 없습니다. 종이에는 하루 안에 처리하거나 버릴 정보만 적고, 다음 주에도 필요할 정보는 앱으로 옮기는 방식이면 충분합니다.

1. 아침에 오늘 할 일 세 가지를 종이에 적습니다.
2. 자료와 링크는 처음부터 앱에 저장합니다.
3. 하루가 끝난 뒤 남겨야 할 종이 메모만 앱으로 옮깁니다.

이 기준을 사용하면 종이와 앱 양쪽에 같은 내용을 중복해 관리하는 문제를 줄일 수 있습니다.
